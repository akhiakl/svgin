# svgin-react

Securely fetch and inline SVGs from URLs as React components, sanitized by default, with client and
server support.

> **Status:** placeholder stub in this monorepo. The real, currently-published implementation lives at
> [`akhiakl/svgin-react`](https://github.com/akhiakl/svgin-react) and will be migrated here in a later
> PR, feature-for-feature at minimum (same export paths: `/client`, `/server`, `/core`, `/suspense`,
> `/shadow`, `/all`; same sanitization guarantees). This package's version continues that existing npm
> package rather than resetting to `0.0.0`.
